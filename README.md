# NORTH. — интернет-магазин курток (PHP + PostgreSQL)

Простой магазин курток на чистом PHP (без фреймворков) и PostgreSQL.
Стили — обычный CSS (`assets/css/style.css`), JavaScript только для интерактивности
(мобильное меню, показ пароля, модальное окно подтверждения удаления).

## Возможности

- Каталог курток с фильтром по категориям, страница товара с выбором размера
- Корзина (в сессии) и оформление заказа (оплата при получении)
- Регистрация и авторизация (`password_hash`/`password_verify`), профиль, история заказов
- Роли `user` / `admin`
- Админ-панель: обзор и пользователи, CRUD курток, заказы (смена статуса), категории

## Требования

- PHP 8.1+ с расширением `pdo_pgsql`
- PostgreSQL

## Установка

1. Создайте **пустую** базу данных:

   ```bash
   createdb -U postgres php_unik
   ```

2. Импортируйте схему (таблицы, категории, 3 демо-куртки, администратор):

   ```bash
   psql -U postgres -d php_unik -f database/schema.sql
   ```

   Демо-администратор: `admin@north.local` / `admin123`

3. Настройте подключение в `config/database.php` (или переменными окружения
   `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`).

4. Запустите встроенный сервер из корня проекта:

   ```bash
   php -S localhost:8000
   ```

5. Откройте http://localhost:8000

## Структура

```
assets/css/style.css     стили (в духе макета: светлая тема, синий акцент #2465d8)
assets/js/main.js        клиентская интерактивность
config/database.php      подключение к БД (PDO)
includes/                init, функции (в т.ч. корзина), шапка и подвал
database/schema.sql      схема БД и демо-данные
index.php                главная + каталог
product.php              страница куртки
cart.php / checkout.php  корзина / оформление заказа
login.php / register.php / logout.php / profile.php
admin/                   панель администратора
```

## Примечания

- SQL — только подготовленные выражения PDO, вывод экранируется через `e()`
- CSRF-защита форм не реализована (учебный проект)
