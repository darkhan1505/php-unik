# TaskFlow  учебный проект (PHP + PostgreSQL + Tailwind CSS)

Простой менеджер задач на чистом PHP (без фреймворков), PostgreSQL и Tailwind CSS
(подключён через CDN, без сборки). JavaScript используется только для
интерактивности на стороне клиента (мобильное меню, показ/скрытие пароля,
модальное окно подтверждения удаления, проверка совпадения паролей).

## Возможности

- Регистрация и авторизация (хэширование паролей через `password_hash`/`password_verify`)
- Сессии, экранирование вывода (XSS)
- CRUD задач: создание, просмотр, редактирование, удаление
- Категории задач (справочная таблица) и связь "многие к одному" с задачами
- Статусы и приоритеты задач, фильтрация списка
- Профиль пользователя: редактирование данных, смена пароля
- Роли пользователей: `user` / `admin`
- Админ-панель: список пользователей, изменение роли, удаление пользователей,
  просмотр всех задач всех пользователей, управление категориями

## Требования

- PHP 8.1+
- PostgreSQL
- Расширение PHP `pdo_pgsql`

## Установка

1. Создайте базу данных:

   ```bash
   createdb -U postgres php_unik
   # или через psql:  CREATE DATABASE php_unik;
   ```

2. Импортируйте схему:

   ```bash
   psql -U postgres -d php_unik -f database/schema.sql
   ```

   Скрипт создаст три таблицы (`users`, `categories`, `tasks`) со связями и триггером
   автообновления `updated_at`, несколько стартовых категорий и демо-администратора:

   - Email: `admin@taskflow.local`
   - Пароль: `admin123`

3. Отредактируйте настройки подключения в `config/database.php`
   (хост, порт, имя БД, пользователь, пароль) под вашу локальную установку PostgreSQL.

4. Запустите встроенный сервер PHP из корня проекта:

   ```bash
   php -S localhost:8000
   ```

5. Откройте в браузере: http://localhost:8000

## Структура проекта

```
config/database.php      подключение к БД (PDO)
includes/init.php        старт сессии, подключение конфигурации
includes/functions.php   вспомогательные функции (флеш-сообщения, авторизация, SVG-иконки)
includes/header.php      общая шапка/навигация (Tailwind CDN)
includes/footer.php      общий футер, модалка подтверждения, подключение JS
assets/js/main.js        клиентская интерактивность
database/schema.sql      схема БД и демо-данные
index.php                главная страница
register.php / login.php / logout.php  регистрация / вход / выход
dashboard.php            личный кабинет со статистикой
tasks.php                список задач с фильтрами
task_form.php            создание/редактирование задачи
task_delete.php          удаление задачи (POST)
profile.php              профиль и смена пароля
admin/                   панель администратора (пользователи, задачи, категории)
```

## Примечания по безопасности

- Все SQL-запросы выполняются через подготовленные выражения PDO (защита от SQL-инъекций)
- Пароли хранятся только в виде bcrypt-хэшей
- Весь пользовательский вывод экранируется функцией `e()` (`htmlspecialchars`)
- CSRF-защита форм отключена по запросу (для продакшена рекомендуется вернуть)
